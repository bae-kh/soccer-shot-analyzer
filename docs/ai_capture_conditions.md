# 영상 촬영 조건과 3단계 검증 대상

2026-10-11 사용자가 설명한 조건과 현재 원본 파일의 FPS·해상도를 확인했다. 촬영 조건은 [조건 기록 JSON](video_capture_conditions.json)에 저장했다. 실제 촬영 FPS, 슬로모션 배율, 초점거리·줌 배율은 아직 확인되지 않았다.

| 영상 | 사용자 설명 | 확인한 파일 정보 | 3단계 검증에 적용할 방향 |
|---|---|---|---|
| test_videos 1~4 | 슬로모션 | 모두 1920×1080; 1·3·4번 30FPS, 2번 약 26.049FPS | 공 위치·크기는 검증 가능. 실제 촬영 시간 확인 전에는 실제 속도 비교를 보류 |
| test_videos 12~14 | 광각·줌 등 설정이 다른 것으로 추정 | 모두 1920×1080, 30FPS | 실제 카메라·렌즈·줌 조건을 확인하고 별도 보정 적용 여부 결정 |
| real_test_videos 10~13 | 줌아웃 촬영 | 모두 1920×1080, 약 29.986~29.989FPS | 다른 영상과 같은 화각으로 계산한 속도를 그대로 비교하지 않음 |
| 나머지 21개 | 조건 미확인 | 1920×1080, 약 30FPS | 정상 배속·동일 카메라가 확인된 것으로 간주하지 않음 |

파일 FPS는 현재 파일에서 읽은 값이다. 원래 촬영 FPS나 슬로모션 배율을 입증하지 않는다. 해상도가 같아도 줌·렌즈가 다르면 초점거리와 화각이 달라질 수 있다.

## 기존 결과 해석

실촬영 10~13번의 기존 추정값은 순서대로 132.4, 142.5, 124.6, 148.6km/h다. 이 값들은 실제 줌 조건에 맞춘 보정 없이 기본 화각 60°로 계산했다. 따라서 실제로 다른 영상보다 빠른 슈팅이라는 근거로 사용하지 않는다. 줌아웃이 얼마만큼의 오차를 만들었는지는 현재 정보로 계산할 수 없다.

슬로모션 1~4번은 기존 실행에서 모두 계산 보류였다. 시간 기준 불일치가 모델 검사에 영향을 줄 가능성은 있지만, 슬로모션이 보류 원인의 전부라는 결론은 내리지 않는다. 실제 배율을 알게 되면 **프레임의 실제 시간을 변환한 뒤 초기 비행 구간 선택과 중력 모델을 다시 계산**한다. 표시된 속도에 배율만 곱하는 방식으로 처리하지 않는다. 중간에 배속이 달라지는 편집 영상인지도 확인해야 한다.

조건 분리 검증 당시에는 이 기록을 계산기에 적용하지 않았다. 이후 촬영 조건 연동 개발에서 `soccer_videos` 아래 상대 경로가 일치하면 기록을 자동으로 적용하도록 연결했다. 실제 촬영 시간이 미확인이거나 해당 카메라·렌즈·줌 보정이 없으면 속도는 표시하지 않고 추적 결과를 유지한다. 업로드 파일 이름만으로 예시 영상과 같은 조건이라고 판단하지 않는다. 자세한 사용법과 검증은 [촬영 조건 연동 보고서](ai_capture_context_results.md)에 정리한다.

## 다음 검증 순서

1. 실촬영 1~9, 14~20을 우선적인 공 중심·크기 검증 후보로 삼는다. 이 16개도 동일 카메라·정상 배속이 확정된 것은 아니다.
2. 실촬영 10~13은 줌아웃 그룹으로 분리해 작은 공·박스 크기의 오류를 검사한다. 속도 계산에는 해당 조건에 맞춘 보정이 필요하다.
3. 테스트 1~4는 공 추적 검증을 유지하고 원래 촬영 FPS 또는 실제 슬로모션 배율을 확인한다.
4. 테스트 12~14는 카메라 설정 변화의 의심 사례로 유지하고 동일 보정값의 적용 가능성을 확인한다.

기존 이동 감지인 테스트 8~10도 고정 카메라의 속도 검증 기준으로 사용하지 않는다. 추적·이동 처리 자체의 검증에는 사용할 수 있다.

[32개 파일 메타데이터와 기존 결과를 연결한 목록](../output/ai_baseline/stage3_capture_conditions_20261011/inventory.json)은 로컬 산출물이다. 여기의 `speed_accuracy_verified: false`는 모든 영상에 독립 속도 기준이 없음을 뜻한다.

2026-10-11 분리 검증 결과는 [공 추적 그룹 검증 보고서](ai_tracking_group_review.md)에 정리했다. 초기 후보 구간 460프레임 전체와 이후 관측 표본 151개를 원본·검출 박스로 대조했다. 실제 속도 정확도 검증은 보류 상태다.
