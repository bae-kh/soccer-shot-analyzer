# 공 크기·초기 비행 입력 개선

2026-10-11. 오검출 차단 이후의 두 번째 작업이다. 공 위치 추적과 속도 계산에 사용할 공 크기를 구분하고, 차기 전 위치 변화만으로 속도 계산을 시작하지 않도록 수정했다. README는 이번 요청에 포함되지 않아 변경하지 않았다.

## 구현 방식

- `backend/ball_size_quality.py`: 공 검출 박스의 긴 축/짧은 축 비율이 1.4를 넘으면 크기 계산에서 제외한다. 길쭉한 박스는 신발·다리가 포함됐거나 영상에 공이 늘어져 보일 수 있다. 최초 공과 배경의 밝기 차이가 충분한 밝은 무채색 공에 한해 전경도 검사한다. 비대칭 박스에서 한 축의 전경 지지가 부족한 경우 추가로 제외한다. 검은 패널이 있는 공은 여러 밝은 조각의 합친 외곽을 사용한다. 밝은 배경·색깔 공·작은 공에는 이 전경 검사를 강제로 적용하지 않는다.
- `backend/analyze_shot.py`: 원본 영상에서 크기 검사 결과를 `ball_size_quality`에 기록한다. 검사에 실패해도 공 위치 관측은 유지한다.
- `backend/shot_physics.py`: 정지 기준점에서 충분히 벗어나고 연속된 두 이동 구간의 방향이 일치하는지 확인한 뒤 비행 후보를 선택한다. 한 번의 위치 점프나 작은 흔들림은 비행으로 확정하지 않는다. 카메라 광축 방향의 슈팅도 처리할 수 있도록 중심 이동이 작은 경우 일관된 크기 변화를 보조 신호로 사용한다. 발과 겹쳐 크기만 갑자기 바뀌면서 중심도 움직인 경우는 이 보조 신호로 시작시키지 않는다.
- `flight_segment`: 실제 선택한 프레임 번호, 비행 이동 확인 여부, 제외한 관측과 이유를 저장한다. 속도 계산에는 기존처럼 충분한 수의 YOLO 관측과 구간 길이가 필요하다. 모델·카메라 이동 검사·불확실성 조건을 통과하지 못하면 속도는 `null`이다.
- `tools/run_ai_baseline.py`: 새 크기 검사 모듈의 해시를 실행 지문에 포함한다.

프레임 단위 임계값은 공의 영상상 크기에 비례한다. 현재 파일 FPS로 처리하며 실제 슬로모션 배율을 추정하거나 자동 보정하는 변경은 아니다. 최대 0.45초의 기존 초기 추적 후보 구간 안에서 선택하므로, 잘못 잡힌 추적 시작이 실제 차기보다 훨씬 이르면 유효 입력 부족으로 보류될 수 있다.

`ball_size_quality.usable: true`는 알려진 거부 조건을 통과했다는 뜻이다. 실제 공 지름을 측정했다거나 가림이 전혀 없음을 보증하지 않는다. 이 검사로 정밀한 공 지름을 새로 추정하거나 검출 박스를 임의 원형으로 교체하지 않는다. 밝기 기반 전경이 불명확한 영상에서는 길쭉한 박스와 이동 조건만으로 판단하므로 부분 가림이 남을 수 있다.

## 자동 검증

관련 테스트 54개가 통과했다. 기존 42개에 크기 검사 6개, 초기 비행 선택 6개를 추가했다. 정상 공·검은 패널·색깔 공·밝은 배경, 발이 가린 비대칭 박스, 차기 전 작은 이동, 단발 점프와 중복 프레임, 광축 방향 슈팅, 유효 크기 부족 시 속도 보류를 확인했다. 알려진 합성 3D 궤적의 속도 복원 검사도 계속 통과한다.

실제 영상 검증은 `output/ai_baseline/stage3_flight_quality_20261011`에 저장했다. 이전 비교 기준은 실제 모델로 실행했던 `stage3_identity_20261011`이다. 별도의 원본 크기 검사 실험인 `stage3_flight_probe_20261011`은 기존 관측에 새 계산을 적용한 오프라인 실험이며 새 모델 실행 결과와 구분한다. 오프라인 실험의 최종 상태·속도·보류 사유는 실제 32개 재실행과 모두 일치했다.

12개 영상의 제거된 32프레임 전체를 원본으로 다시 검토했다. 실촬영 14번 f84와 17번 f68처럼 실제 공이 보이지만 연속 이동 확인이 부족해 제외된 정상 초기 관측도 있다. 이 변경은 입력을 보수적으로 줄이는 방식이며 모든 제거 프레임이 오검출이라는 뜻이 아니다. 테스트 3번 f116~119처럼 발 주변의 둥근 공 박스도 일부 후보에 남는다. 이 영상은 유효 후보 4개로 속도 산출을 보류했다. 사람·발을 분할해 모든 접촉을 판별하는 기능을 구현한 것은 아니다.

추정값이 바뀐 영상은 아래 5개다. 계산 구간·크기 입력이 달라진 결과이며 실제 속도가 더 정확해졌다는 증거는 아니다.

실촬영 16번은 발과 겹친 초기 f57 박스를 제외하면서 75.0→86.6km/h로 바뀌었다. 이처럼 구간 선택에 민감한 사례는 독립 속도 기준으로 추가 검증해야 한다. 실촬영 줌아웃 10~13번은 이번에도 기본 화각의 기존 추정값을 유지하므로 절대 속도 검증 자료로 삼지 않는다. 보류 17개의 사유는 크기 불일치 4, 관측 부족 5, 속도 불확실성 2, 투영 불일치 3, 카메라 이동 3개다.

## 이번 작업 이후

다음은 실제 촬영 시간과 카메라·줌별 보정을 연결하는 작업이다. 슬로모션 테스트 1~4는 실제 촬영 FPS 또는 배율이 필요하고, 실촬영 10~13 및 설정 차이가 의심되는 테스트 12~14는 촬영 조건에 맞는 카메라 보정이 필요하다. 속도의 절대 정확도는 독립 기준을 확보한 뒤 검증한다.
