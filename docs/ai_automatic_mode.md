# 설정 없이 사용하는 자동 분석 모드

> 이 문서는 2026-10-12 구현 기록입니다. 현재 동작은 [9주차 구현·검증](week9_goal_scoring_results.md)을 참고하세요. 화면 영역 후보와 골라인 판정은 분리됐고 기존 부분 점수는 기본 경로에서 사용하지 않습니다.

2026-10-12. 사용자가 별도 설정 없이 속도·골인 여부·점수를 제공하도록 요청했고, 기본 영상 조건은 줌 없음·슬로모션 없음으로 가정하도록 명시했다. 이번 변경은 그 가정을 사용하는 자동 추정 모드를 기본값으로 제공한다. 실제 촬영 조건이 확인됐다는 뜻은 아니다.

## 사용 흐름

첫 화면에서는 영상 파일만 선택한다. 기본값은 `analysis_mode=automatic`, `timing_mode=normal`이며 보정 프로필·골대 실측·채점 설정 파일을 요구하지 않는다. 설정 메뉴는 닫힌 선택 메뉴로 이동했다. 이전 앱을 열어 둔 경우 새로고침하면 새 기본값으로 시작한다.

서버도 분석 옵션이 없거나 빈 객체이면 동일한 자동 모드를 사용한다. 따라서 프론트엔드만 바뀐 동작이 아니다. 명시적인 기존 촬영 옵션은 호환성을 위해 보정 자료 기반 모드로 처리한다. 선택 메뉴에서 `calibrated` 모드를 고르면 기존 보정·촬영 조건 검사를 사용할 수 있다.

## 자동 속도

- 정상 속도에서는 파일 FPS를 실제 시간의 근사값으로 사용하고 `ASSUMED_NORMAL`로 기록한다. 사용자 확인이나 카메라 보정 성공으로 기록하지 않는다.
- 보정 정보가 없으면 수평 화각 60도, 공 반지름 0.11m, 줌 없음 가정을 사용한다. 화각은 기기의 실제 메타데이터에서 자동 측정한 값이 아니다.
- 기존 공 크기 기반 3D 위치와 초기 비행 구간의 물리 모델로 속도를 추정한다. 자동 모드에서도 예측점·CSRT 크기를 속도 관측으로 사용하지 않는다.
- 카메라 이동, 불량 공 크기, 관측 부족, 큰 모델 오차 등은 계속 검사한다. 결과를 만들기 위해 해당 검사를 없애지는 않았다.
- 보정 없이 계산한 값은 `speed_basis=ASSUMPTION_BASED`다. 실측 정확도는 미검증이다.

예시 영상의 기존 슬로모션·줌 기록은 삭제하거나 정상 영상으로 바꾸지 않았다. 자동 모드는 요청한 정상·줌 없음 가정을 덮어 적용하며, 기존 기록과 다를 경우 `SAMPLE_CAPTURE_REPORT_DIFFERS_FROM_AUTOMATIC_DEFAULTS`를 남긴다. 따라서 해당 영상에서 나온 값을 실제 촬영 속도의 정답으로 사용하면 안 된다.

## 자동 골인 가능성

자동 모드는 물리적인 골라인 통과와 별도의 `goal_prediction`을 반환한다.

| 상태 | 화면 | 근거 |
|---|---|---|
| `GOAL_LIKELY` | 골인 추정 | 영상의 골대 영역 밖에서 안으로 공이 연속 관측됨, 또는 별도 골대 면의 통과 추정 |
| `OUTSIDE_LIKELY` | 골대 밖 추정 | 관측된 접근 이후 골대 세로 영역에서 기둥 바깥 공 박스를 2회 연속 관측함 |
| `UNDETERMINED` | 골인 판단 어려움 | 카메라 움직임·관측 누락·불충분한 통과 근거 등 |

영상 영역 진입 후보를 자동 모드의 골인 가능성으로 사용한다. **깊이를 확인한 확정 골인이 아니다.** 기존 `physical_goal`과 `goal_entry.physical_goal_status`는 별도 골대 실측이 없으면 계속 `UNDETERMINED`이며 `physical_goal_confirmed=false`다. 후보 없음이나 관측 종료만으로 실축을 선언하지 않는다.

현재 골대 밖 추정 규칙은 아래에서 골대를 향하는 영상 관측의 기둥 바깥 통과에 한정된다. 모든 촬영 각도·크로스바 위 통과·가림을 자동 판독하는 규칙은 아니다.

## 자동 참고 점수

기본 규칙은 `automatic_v1`이며 사용자 요청에 따라 별도 확인 없이 적용되는 프로토타입 기준이다. 경기 규정이나 실험으로 검증된 실력 평가표는 아니다.

```
속도 항목 = clamp((속도 km/h - 20) / 80, 0, 1)
위치 항목 = max(0, 1 - 정규화 통과 위치와 골대 중심의 거리 / sqrt(0.5))
참고 점수 = 100 × (속도 항목 × 0.4 + 위치 항목 × 0.6)
```

위치 항목의 기본 목표는 골대 중심이며 영상 좌표를 사용한다. 기둥 가까운 슛이 축구적으로 나쁘다는 뜻이 아니고, 골대 중심을 목표로 선택한 이 규칙에 따른 점수다. 골인 추정만으로 공인 골라인 판정을 대신하지 않는다.

한 항목만 사용 가능하면 그 항목의 비중을 100%로 환산해 부분 점수를 제공한다. 화면에 `속도 기준 · 일부 항목` 또는 `골대 중심 기준 · 일부 항목`을 표시한다. 골대 밖 추정은 별도 규칙으로 0점을 제공한다. 두 항목 모두 근거가 부족하면 점수는 null이며, 이를 실패 점수 0으로 바꾸지 않는다. 모든 자동 점수는 `PROVISIONAL`, `accuracy_validated=false`다.

## 구현과 검증

- `backend/capture_context.py`: 자동 모드의 시간·화각 가정과 기존 촬영 기록의 출처 관리.
- `backend/automatic_analysis.py`: 영상 기반 골인 가능성, 기본 점수와 부분 점수, 결과 코멘트.
- `backend/analyze_shot.py`: 기본 모드 적용, 계산·저장 JSON·반환 결과 연결.
- `frontend/src/components/Upload.jsx`, `CaptureSettings.jsx`: 기본값 변경과 선택 설정 메뉴.
- `frontend/src/components/Result.jsx`, `frontend/src/lib/goalResult.js`: 추정 골인·속도·점수와 사용한 항목 표시.
- `tools/audit_ai_geometry.py`, `compare_automatic_mode.py`: 실제 출력에서 자동 계산의 재검사와 기존 관측 보존 검사.

Python 141개와 프론트엔드 13개 테스트, lint·프로덕션 빌드가 통과했다. 자동 모드에서 보정 없이 합성 속도가 계산되는지, 정밀 모드 및 잘못된 보정은 계속 차단되는지, 가정과 촬영 기록이 구분되는지, 골인/실축의 근거 조건, 부분 점수, 0점의 SSE 전달을 검사했다.

현재 예시 영상 32개를 실제 모델로 다시 실행했다. 결과는 다음과 같다.
