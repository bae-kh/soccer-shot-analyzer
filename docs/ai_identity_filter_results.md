# 오검출·추적 이탈 차단 결과

2026-10-11. 촬영 조건별 원본 검토 후 제안한 후속 작업 중 **첫 번째 작업**을 구현했다. 장갑·광고판 글자·영상 UI·빈 배경을 공으로 채택하는 문제를 줄이는 변경이다. 공 크기와 초기 비행 구간의 품질 개선은 다음 작업이다.

## 구현한 내용

1. 최초 공을 선택한 원본 프레임에서 공 안쪽의 색상·밝기 분포를 저장한다. 이후 YOLO 후보와 CSRT 추적 후보가 이 외형과 크게 다른 경우 위치 보정에 사용하지 않는다. 흰색 공만 허용하는 방식은 아니며 노란색 공도 테스트했다.
2. 새 위치의 후보를 슈팅 전 원본 배경 및 직전 프레임들과 비교한다. 공이 도착한 것처럼 보이지만 화면 내용이 거의 변하지 않았다면 광고판 글자·UI·배경 후보로 거부한다. 카메라 정렬은 특징점 추적과 오차 검사를 통과했을 때만 추가 비교에 사용한다. 이미 공이 있던 위치와 중복 프레임은 보존하도록 했다.
3. CSRT가 공과 다른 대상을 따라가기 시작하면 해당 관측을 폐기하고 추적기를 해제한다. 정상 YOLO 검출이 들어오면 다시 초기화한다. 관측이 없는 동안에는 기존 제한 시간만 예측하고, 예측점은 속도 계산에 넣지 않는다.
4. 채택한 관측의 검사 결과와 거부한 후보의 원인·박스를 추적 JSON에 남긴다. 거부된 후보로 Kalman 상태를 보정하지 않는다.

색상·밝기 점수는 확률이나 학습 모델의 신뢰도가 아니다. YOLO 가중치를 새로 학습한 변경도 아니다. 최초 공 선택이 잘못되거나 공의 외형이 크게 변하면 이 검사도 실패할 수 있으므로, 전체 프레임의 정확도가 입증됐다고 해석하지 않는다.

## 수정 파일

| 파일 | 역할 |
|---|---|
| `backend/ball_observation.py` | 원본 공 외형·배경 변화 검사 추가 |
| `backend/ball_tracking.py` | YOLO·CSRT 관측 채택 전에 검사, 거부 기록 추가 |
| `backend/analyze_shot.py` | 최초 공 프레임 전달, ROI 재검출 및 CSRT 해제 연결 |
| `tools/run_ai_baseline.py` | 새 검사 모듈을 실행 소스 지문에 포함 |
| `tests/test_ball_observation.py` | 정상 공·빠른 공·노란 공·중복 프레임 보존 및 오검출 차단 6개 테스트 |
| `tools/probe_ball_observations.py` | 기존 박스에 대한 후보 검사 실험; 실제 재추론 결과와 구분 |
| `tools/compare_ball_identity.py` | 오검출 사례·정상 공 비교 지점 및 관측 기록 검증 |
| `tools/review_identity_changes.py` | 초기 구간에서 바뀐 관측의 원본 확인 이미지 |
| `tools/review_identity_controls.py` | 공 재검출 및 정상 CSRT 위치 변화의 원본 비교 이미지 |

속도·공 크기 계산 알고리즘, Frontend 및 모델 가중치는 이번 작업에서 변경하지 않았다. 추적 데이터에 `observation_validation`, `rejected_observations` 및 요약 필드를 추가했다.

## 실제 실행과 검증

현재 남아 있는 실촬영 20개와 테스트 12개를 모두 실제 모델로 다시 실행했다. 결과 폴더는 `output/ai_baseline/stage3_identity_20261011`이다. 입력 영상·모델·AI 소스·보정 파일 지문이 실행 결과와 일치했고, 좌표·프레임·미디어 및 채택/거부 기록의 불변 조건 검사를 통과했다.

| 항목 | 결과 | 해석 |
|---|---|---|
| 실제 영상 재실행 | 32/32 완료 | 모든 실행과 결과 파일 확인 |
| 원본으로 확인했던 오검출 사례 | 8/8 해당 프레임의 잘못된 박스 제거 | 전체 영상의 오검출률을 뜻하지 않음 |
| 정상 공 비교 지점 | 29곳 중 28곳 위치 기준 통과 | 원본 검토로 선정한 기존 공 관측과 비교; 정밀 중심 정답은 없음 |
| 나머지 정상 공 비교 지점 | 실촬영 18번 f113, 기존 중심과 약 7.90px 차이 | 원본 비교에서 변경 후에도 같은 공을 검출함을 확인. 자동 통과 수를 29로 바꾸지 않음 |
| 자동 테스트 | 42개 통과 | 추적 16 + 새 외형 검사 6 + 물리 15 + 실행 도구 5 |
| 속도 산출 상태 | 추정 15 / 보류 17 유지 | 실제 속도 정확도를 검증한 결과가 아님 |
| 평균 실행 시간 | 기존 13.19초 → 22.73초 | 약 72% 증가; 모델 로딩 포함, 업로드·화면 표시 제외 |

거부된 후보 기록은 총 311건이다. 공 외형 불일치 259건, 변하지 않은 배경 51건, CSRT 밝기 불일치 1건이다. 한 프레임에 여러 후보가 있을 수 있으며 **311건 모두를 오검출 정답으로 확인한 것은 아니다**.

| 기존 오검출 | 이번 결과 |
|---|---|
| 실촬영 14번 f87 장갑 | 실제 관측으로 채택하지 않음 |
| 실촬영 18번 f102 장갑 | 실제 관측으로 채택하지 않음; f104·105에서 원본 공 재검출 확인 |
| 실촬영 5번 f90 빈 배경 | CSRT 관측 폐기 |
| 실촬영 15번 f114 빈 울타리 | CSRT 관측 폐기 |
| 실촬영 16번 f58 빈 바닥 | CSRT 관측 폐기 |
| 테스트 12번 f33 빈 잔디 | CSRT 관측 폐기 |
| 테스트 13번 f79 광고판 O 글자 | YOLO 관측 폐기, 3D 입력에서도 제거 |
| 테스트 10번 f51 재생 UI | 관측으로 채택하지 않음 |

프레임 번호는 0부터 시작한다. 실촬영 14번 f87은 기존에도 박스 종횡비 검사로 3D 입력에서 제외됐었다. 이번에는 추적 관측 자체에서도 제거했다. 테스트 13번 f79는 기존 3D 입력에 포함됐던 실제 오검출이다.

초기 후보 구간에서 관측 상태나 중심이 바뀐 9개 영상의 36프레임을 원본 이미지로 검토했다. 실촬영 18번 f104·105는 장갑에서 실제 공으로 재검출 위치가 바뀌었다. 테스트 8·9번의 3프레임은 CSRT가 공을 계속 따라가되 박스 위치가 바뀐 경우였다. 이 변화는 정확한 공 지름 검증을 대체하지 않는다.

촬영 조건별 결과는 일반 실촬영 후보 16개 중 추정 10개, 줌아웃 실촬영 4개 중 추정 4개, 슬로모션 4개 중 추정 0개, 카메라 설정 차이가 의심되는 테스트 3개 중 추정 0개, 나머지 테스트 5개 중 추정 1개다. 모든 영상에서 실제 카메라 보정이 적용되지 않았으므로, 이 수치는 처리 상태만 나타낸다.
