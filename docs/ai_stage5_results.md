2026-10-11. 4단계의 범위를 **영상 골대 영역 진입 후보·판정 보류·결과 표시·점수 미평가 구조**로 검수하고, 5단계의 전체 영상 실행·후기·보류 표본 검토와 확인된 CSRT 오류 보완을 완료했다. 실제 골인·속도 정확도의 최종 합격을 선언하는 문서가 아니다. 단계 완료 후 사용자 요청에 따라 README에도 결과와 남은 작업을 반영했다.

## 4단계 검수 판단

**이 범위의 구현 검증을 통과했으므로 5단계로 진행할 수 있다.** 초기 물리 모델의 외삽이나 공 중심만의 겹침으로 골인을 확정하지 않는 계약, 속도 null과 독립적인 후보 처리, 관측 근거·보류 사유·점수 미평가의 반환과 화면 연결을 확인했다.

- 수정 전 현재 소스·모델·입력 해시가 4단계 실행 기록과 모두 일치했다.
- 32개 결과의 좌표·원본 관측·후보 근거·MP4/JSON/사진 규약 검사와 Python 테스트 84개를 재실행해 통과했다.
- 4단계의 실제 업로드→YOLO·CSRT→SSE→사진 조회 기록과 프론트엔드 결과 표시 구현을 대조했다.
- ‘모든 추적이 정확하다’, ‘골인 판정 완성’, ‘실제 속도 정확도 검증 완료’는 합격 기준에 포함하지 않았다. 이런 주장은 현재 증거로 뒷받침할 수 없다.

## 확인한 오류와 수정

### CSRT가 마지막 공 위치 근처 배경을 유지하는 문제

실촬영 2번 f99는 공이 없는 배경을 관측으로 채택했다. 기존 검사는 후보가 마지막 YOLO 위치에서 충분히 멀어졌을 때만 배경 변화를 검사했다. CSRT가 마지막 위치 근처에 붙어 있으면 검사를 건너뛸 수 있었다.

`backend/ball_observation.py`에서 CSRT는 이동 거리가 작아도 촬영 전 배경과 비교하게 했다. 처음 공이 놓인 영역은 보존하고, 공이 도착해 배경이 달라진 위치에서는 정지·반복 프레임도 허용한다. 정렬 가능한 경우 정렬한 배경, 그렇지 않으면 화면 배경을 사용한다. 배경 변화 3 미만과 초기 공 영역 밖이라는 조건은 휴리스틱이며 실제 전체 정확도를 보증하지 않는다.

### CSRT가 어두운 가림 물체를 공으로 유지하는 문제

실촬영 15번 f110·112에서는 장갑·가림 물체 쪽으로 이탈했다. 검출기 확인이 없는 CSRT에 한해 밝기 분포 일치가 낮고, 밝은 부분과 평균 밝기가 동시에 크게 감소하면 관측으로 채택하지 않도록 보완했다. 단순히 흰 공만 허용하는 조건은 아니다. YOLO의 기존 허용 조건과 공 색상 검사는 유지했다.

전체 수정 전 CSRT 694개에 보완 규칙을 대조한 결과 실촬영 2 f99, 실촬영 15 f110·112의 3개가 제외 대상이 됐다. 나머지를 유지했지만 이는 저장된 박스에 대한 사전 검사다. 전체 재추적에서 뒤 프레임이 어떻게 달라지는지도 별도로 비교한다.

### 카메라 검사 시작이 공 관측보다 늦는 문제

테스트 8·9번은 골대 기준 프레임 f17보다 슈팅 시작 f14가 앞선다. 기존 전체 골대 카메라 검사는 f17에서 시작해 f14~16을 범위에서 제외했다. `backend/goal_entry.py`의 `goal_camera_interval`과 `backend/analyze_shot.py`를 연결해 **골대 기준 프레임과 전체 공 관측을 모두 포함하는 범위**를 사용한다. 이 두 영상에서는 f14부터 검사한다. 시작·중간·끝 세 프레임의 검사 방식 자체는 유지하므로 전 프레임 고정을 증명하지는 않는다.

## 남은 문제와 개발 순서

1. **추적 정확도 보완:** 실촬영 5 f101의 배경 추적 의심 관측과 테스트 12 f37~39의 신발·공 가림 구간은 해결됐다고 선언하지 않는다. 원본에서 공의 가시성·대상을 분리해 추가 검증하고, 가림·재검출 검사를 보완해야 한다. 밝기 기준을 무작정 올려 정상 공까지 제거하지 않는다.
2. **카메라 검사 검증:** 실촬영 3·18·20은 원본 표본에서 화면 크기·구도가 달라 보인다. 줌·크롭·안정화·촬영 방식 중 어느 원인인지는 확정하지 않는다. 테스트 슬로모션 1·3·4의 작은 이동·배경 흐름 판정은 오탐 여부의 추가 검증이 필요하다. 배경 가림과 실제 카메라 이동을 구분하는 작업이 남았다.
3. **실제 속도 검증:** 실제 촬영 시간·배율·설정별 보정·독립 속도 기준은 아직 없다. 현재 32개 속도는 계속 보류한다. 조건 확인과 합성 계산 검증을 실제 속도 정확도 검증으로 대체하지 않는다.
4. **골인·점수:** 영상 사각형 겹침 후보를 실제 골라인 통과로 확정하지 않는다. 실제 골대 평면·공의 깊이·공 전체 통과 근거와 합의된 채점 기준이 있어야 실제 골인·점수 계산을 연결할 수 있다.

따라서 5단계의 현재 결과는 **전체 파일 실행·계약 검증과 표본 검토, 확인된 오류의 보완**이다. 남은 추적·카메라 판정 문제와 현장 측정 검증을 포함한 최종 정확도 합격은 아직 보류한다.
