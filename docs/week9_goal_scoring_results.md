# 9주차 골라인 판정과 외곽 채점 구현 기록

2026년 11월 9일 · [설계서](week9_goal_scoring_design.md)

영상 안에서 공과 골대가 겹치면 진입 후보로 기록한다. 골인 또는 골대 밖 통과 추정은 카메라 보정과 골대 실측, 골라인을 지나가는 공 전체의 연속 관측이 있어야 반환한다. 이 결과와 종합 점수는 실측 정확도가 확인되기 전까지 참고값이다.

- 자동·보정 모드는 기본 규칙 `week9_outer_v1`을 공유한다. 골인한 공의 교차 위치가 골대 중심에서 멀수록 위치 점수가 높다. 속도 40%와 위치 60%를 적용하고, 골인 점수에는 보정과 실제 촬영 시간이 확인된 속도가 필요하다.
- 골대 밖 통과 근거가 충분하면 0점, 판정 또는 필수 입력이 부족하면 미평가다. 기존 사용자 지정 목표점 채점은 명시적으로 선택할 때만 해당 규칙으로 계산한다.
- 결과 화면은 골라인 판정을 먼저 보여주고 화면 진입 후보, 속도, 점수 또는 보류 사유를 각각 보여준다. 결과 이미지와 저장 JSON에도 관측과 판정을 분리해 기록한다.

## 실영상 회귀 검증

이전 실험에는 32개 원본이 있었다. 이번 작업 시점에 폴더에 있는 원본 20개는 실제 모델로 새로 실행했고, 원본이 없는 12개는 이전 추적 JSON의 관측을 이용해 영상 후보·점수 정책을 재확인했다. 기록 재검사는 영상이나 모델을 재실행한 결과로 집계하지 않는다.

테스트 11번은 진입 후보(40~41프레임)와 81.8 km/h 자동 추정을 유지했다. 이전의 골인 추정과 51.2점 대신 골라인 미확정과 종합 점수 미평가가 표시된다. 실촬영 3번·13번도 기존 속도를 유지하고 이전 속도 단독 점수 98.0점·100.0점은 표시하지 않는다.

테스트 11번의 실제 multipart API 업로드를 자동·보정 모드로 각각 실행했다. 두 모드 모두 SSE 진행 이벤트 19개, 결과 JPEG HTTP 200을 확인했고 응답과 추적 JSON의 골라인·채점 결과가 일치했다. 보정 모드는 실제 시간 정보를 넣지 않아 속도도 보류했다. [React 결과 미리보기](../output/week9_goal_scoring_20261109/test_videos/review/video11_result.html)는 실제 자동 분석 반환값으로 렌더링했고, 진입 후보·골라인 미확정·속도·종합 점수 미평가를 확인했다.

Python 테스트 142개, Node 테스트 14개, ESLint와 Vite 빌드가 통과했다. 합성 관측으로 휘어 들어오는 공, 크로스바 위·기둥 옆 통과, 경계 접촉, 가림과 추적 누락을 구분했다. 같은 60 km/h에서 중앙 20.0점, 외곽 53.9점, 모서리 쪽 68.0점을 확인했다. 이 점수의 60 km/h는 테스트 입력이며 실측 속도가 아니다.
